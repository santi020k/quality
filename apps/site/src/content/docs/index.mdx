## Native analyzers. One predictable interface.

`quality` detects your repository, resolves local tooling, runs independent checks concurrently, and normalizes every result for developers and CI.

<CardGrid stagger>
  <Card title="Adopt without a flag day" icon="add-document">
    Baseline existing findings once, then prevent new regressions without hiding tool crashes or missing dependencies.
  </Card>
  <Card title="Fast pull-request feedback" icon="rocket">
    Scope file-capable analyzers to Git changes while keeping project-wide tools correct.
  </Card>
  <Card title="Review where the code lives" icon="approve-check">
    Emit native GitHub annotations and SARIF reports from the same deterministic run.
  </Card>
  <Card title="Extend without a fork" icon="puzzle">
    Configure external analyzers with explicit commands, file scopes, and normalized parsers.
  </Card>
</CardGrid>
